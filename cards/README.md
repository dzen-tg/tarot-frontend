# Карты колоды

Рисунки Памелы Колман Смит из колоды Райдера–Уэйта–Смит 1909 года (общественное достояние).
Источник сканов: Wikimedia Commons (файлы «RWS Tarot NN …», «CupsNN», «SwordsNN», «WandsNN», «PentsNN»).

Имя файла — номер карты в колоде бота: 00–21 Старшие арканы, 22–35 Кубки, 36–49 Мечи,
50–63 Жезлы, 64–77 Пентакли (Туз … Король). Формат WebP, 300×520.

На картах 06, 15, 17, 19, 20, 21 фигуры одеты (отредактированные версии).
